# Melhorias SEO para Notícias - CNRC

## 1. Schema.org JSON-LD para Artigos
Adicionar structured data do tipo Article/NewsArticle em cada página de notícia.

Benefícios:
- Rich snippets no Google (imagem, data, autor)
- Melhor compreensão do conteúdo pelos motores de busca
- Elegibilidade para Google News

Implementação:
- Criar função em lib/schema-org.ts (já existe para LocalBusiness)
- Adicionar ao generateMetadata() ou como component
- Campos: headline, datePublished, dateModified, author, image, publisher

## 2. Sitemap Dinâmico para Notícias
Gerar sitemap.xml incluindo todas as notícias com prioridade e changefreq.

Benefícios:
- Facilita descoberta de novo conteúdo
- Indica ao Google frequência de atualizações
- Melhora indexação

Implementação:
- app/sitemap.ts com getAllNews()
- Incluir lastmod (data da notícia)
- Priority 0.8 para notícias recentes
- Changefreq: weekly

## 3. Robots Meta Tags
Adicionar controlo granular de indexação por página.

Benefícios:
- Controlar o que é indexado
- Evitar duplicate content issues
- Gerir crawl budget

Implementação:
- Adicionar ao pageMetadata() em lib/metadata.ts
- robots: { index: true, follow: true }
- noarchive para conteúdo sensível se necessário

## 4. Reading Time
Calcular e mostrar tempo estimado de leitura.

Benefícios:
- Melhora user experience
- Reduz bounce rate
- Pode ser incluído em schema (timeRequired)

Implementação:
- Função em lib/utils.ts (palavras / 200 wpm)
- Mostrar abaixo do título ou com data
- Incluir em Article schema

## 5. Author Markup
Sistema de autores para artigos.

Benefícios:
- Authorship em rich snippets
- E-E-A-T (Expertise, Experience, Authoritativeness, Trust)
- Credibilidade

Implementação:
- Adicionar campo author ao frontmatter MDX
- Página de perfis de autores (opcional)
- Schema Person/Organization em Article schema

## 6. Published/Modified Dates em Schema
Datas estruturadas para motores de busca.

Benefícios:
- Freshness signals para ranking
- Rich snippets com data
- Google News eligibility

Implementação:
- datePublished (frontmatter.date)
- dateModified (git last commit ou campo manual)
- Formato ISO 8601

## 7. RSS Feed

- Agregadores e readers

Implementação:
