# Sketch 002: Typography Treatment

## Design Question
How bold should the office name typography be? Building on the full-bleed overlay layout from Sketch 001, this explores different typographic approaches for the office names - from minimal elegance to maximum impact.

## Variants

- **A: Minimal Elegant** — Medium-weight serif at comfortable reading size. Refined, sophisticated, doesn't compete with the photography. Classic luxury approach.

- **B: Bold Uppercase** — Extra-large uppercase display type that dominates the section. Maximum impact and authority. Makes a powerful statement.

- **C: Decorative Italic** — Large italic serif with decorative elements (gold lines, large ghosted numbers). Editorial, distinctive, adds visual rhythm and ornamentation.

## What to Look For

- **Hierarchy**: Which treatment establishes clear visual hierarchy between eyebrow, office name, and description?
- **Prestige**: Which feels most prestigious and authoritative?
- **Readability**: Which remains readable while being dramatic?
- **Photography Balance**: Which complements rather than competes with the office imagery?
- **Consistency**: Which will work well across all 4 office names (Lisboa, Barreiro, Montijo, Braga)?
